# Texts From Your Future Self

It's you from 2046. Do NOT buy the blue mug tomorrow - it chips on day one and I still think about it every morning. The house fire in 2031? We rebuilt. The mug haunts me.

## How to run

1. Run `python3 main.py` — it writes the text above to `/output/entry.txt`.
